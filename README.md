För att kunna koppla upp sig i projektet behöver användaren använda sig utav UserSecrets och följande behöver finnas i den filen, lösenord och användare är standard för databasen:
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=studentpsql.miun.se; Port=5432; Database=DsuDb5; Username=; Password="
  }
}
